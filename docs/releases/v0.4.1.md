# hazelcast-toolkit 0.4.1

## Focus

Post-release health observability hardening.

## Changes

- Extended the Boot 2 consumer smoke test to enable
  `hazelcast.toolkit.health.enabled=true`.
- The Boot 2 smoke now verifies that the toolkit health indicator is created and
  reports `UP` when the consumer provides a running `HazelcastInstance` stub with
  a visible cluster member.
- This improves published-consumer confidence for the health indicator introduced
  in `0.4.0` without changing the published `0.4.0` artifacts.
