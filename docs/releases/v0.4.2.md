# hazelcast-toolkit 0.4.2

## Focus

Diagnostic response consistency.

## Changes

- Map near-cache diagnostics now include a `near.reason` field when Near Cache is
  disabled.
- The map diagnostic response now mirrors the JCache diagnostic contract:

```json
{
  "status": "OK",
  "name": "books",
  "mapName": "books",
  "enabled": false,
  "near": {
    "enabled": false,
    "reason": "Near Cache is not enabled"
  }
}
```

- Added unit coverage for map near-cache diagnostics when Near Cache is disabled.
- Hardened Hibernate L2 performance characterization tests against cold-read
  timing outliers on shared CI runners.
- Updated observability and troubleshooting docs with the map diagnostic contract.
