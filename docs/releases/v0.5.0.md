# hazelcast-toolkit 0.5.0

## Focus

Starter polish: make auto-configuration behavior easier to reason about and
safer to validate before release.

## Changes

- Expanded Boot 2, Boot 3, and Boot 4 auto-configuration condition coverage for
  Hibernate L2 behavior.
- Added tests proving the Hibernate L2 customizer is opt-in via
  `hazelcast.toolkit.hibernate.l2.enabled=true`.
- Added fail-fast coverage for `extended-config=true` with `region-factory=JCACHE`
  when no `javax.cache.CacheManager` bean is available.
- Added fail-fast coverage for native Hibernate L2 modes when
  `com.hazelcast:hazelcast-hibernate` is missing from the classpath.
- Made native Hibernate L2 classpath validation classloader-aware so the
  fail-fast check respects the application/test classloader instead of the
  system classloader.
- Updated the compatibility matrix for the `0.5.x` starter support contract,
  including Boot, Spring Framework, Hibernate, Hazelcast, JCache, Micrometer,
  Boot 4 stub notes, and release verification expectations.
- Strengthened Spring Boot configuration metadata tests so all public
  `hazelcast.toolkit.*` keys and enum hints are checked.
- Hardened shared Hibernate L2 performance characterization assertions against
  near-cache baseline timing outliers.
- Updated stale near-cache actuator property documentation to describe typed JPA
  metamodel id conversion instead of `Long`-only conversion.
