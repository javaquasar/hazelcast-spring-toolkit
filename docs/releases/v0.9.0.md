# hazelcast-toolkit 0.9.0

## Focus

Compact scanning API cleanup.

## Changes

- Deprecated the legacy `CompactClassesScanner` and `CompactScanResult`
  compatibility API while keeping it available for existing callers.
- Documented the preferred runtime path: `ClassScanner` together with
  `CompactClientConfigSupport`.
- Moved the Boot 3 example compact scanning test from the legacy compat scanner
  to the actual runtime registration path.
- Added negative coverage for explicit `@HzCompact(serializer = ...)`
  registration:
  - serializer class without a no-args constructor
  - serializer returning a different `getCompactClass()` than the annotated type

## Verification

./gradlew :toolkit-runtime:test --tests io.github.javaquasar.hazelcast.toolkit.hazelcast.compact.CompactClientConfigSupportTest
