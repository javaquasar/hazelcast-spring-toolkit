# Release Notes: v0.11.1

## Migration Verification

- Added a real member-to-client migration integration scenario for the Spring
  Boot 2, 3, and 4 starters.
- The scenario starts an independent Hazelcast member, runs the application as
  a second cluster member, writes distributed map data, and gracefully stops
  the application context.
- It then keeps the anchor cluster alive, restarts the same application setup as
  a Hazelcast client, verifies the original value, and writes a new value that
  remains visible from the cluster member.
- Shared the runtime test logic through internal test fixtures so all supported
  Spring Boot lines verify the same topology transition contract.

## Compatibility

- No public API or production runtime behavior changed.
- The Hazelcast baseline remains `5.7.0` and Java remains `17`.

## Verification

- Run the member-to-client migration test for each Spring Boot starter.
- Run the complete release-confidence matrix before publishing to Maven
  Central.
