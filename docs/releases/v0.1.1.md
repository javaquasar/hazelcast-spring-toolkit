# hazelcast-toolkit v0.1.1

`hazelcast-toolkit` is a Spring Boot integration toolkit for Hazelcast focused on
reducing boilerplate around client configuration, Compact serialization, IMap
listeners, Hibernate second-level cache, and observability.

## Highlights

- Published Maven artifact IDs now use the `hazelcast-toolkit-*` prefix for clearer
  discovery in Maven Central
- Release packaging and signing flow improved for Maven Central publication
- Root-level bundle collection task added so all Central upload ZIPs can be gathered
  into one directory
- Boot 2 and Boot 3 near-cache invalidation integration tests further stabilized for
  full-suite execution
- `example-spring-boot3` verified against published artifacts as a real consumer path

## Published Modules

## Coordinate Change

Starting with `v0.1.1`, published artifact IDs use the `hazelcast-toolkit-*` prefix.

Example:

Old `0.1.0` coordinate:

```groovy
implementation "io.github.javaquasar:toolkit-spring-boot3:0.1.0"
```

New `0.1.1` coordinate:

```groovy
implementation "io.github.javaquasar:hazelcast-toolkit-spring-boot3:0.1.1"
```

This change applies to all published modules, not just the Boot starters.

## Key Capabilities

- Smart Hazelcast client naming with toolkit-level naming policy
- Compact scanning through a clean `ClassScanner` abstraction
- Serializer-aware Compact registration
- Automatic listener wiring for `@HzIMapListener`
- Shared integration test infrastructure across Boot 2 and Boot 3
- Production-oriented observability with Micrometer meters for:
  - near-cache metrics
  - Hibernate L2 metrics

## Notes

- For Hibernate L2 with `JCACHE`, prefer `extended-config=true` to bind Hibernate
  to the toolkit-managed `CacheManager`
- `HAZELCAST_LOCAL` remains the recommended native region-factory mode for most
  Hazelcast client applications
- `hazelcast.toolkit.client.base-name` acts as the toolkit naming prefix; if no
  naming inputs are configured, the toolkit generates a unique fallback client name
- `hazelcast.client.enterprise-license-key` is optional and only needed when the
  application connects to Hazelcast Enterprise

## Not Included In This Release

### `toolkit-spring-boot4`

Boot 4 support exists in the repository, but it is still intentionally **not**
published as part of `v0.1.1`.

Reason:

- Spring Boot `4.0.0` still does not provide the full JPA / Hibernate and Actuator
  runtime story required for the toolkit's full Boot 4 feature set
- publishing the Boot 4 starter now would still create misleading expectations for
  features that are not yet production-ready in that ecosystem

### `toolkit-testcontainers`

`toolkit-testcontainers` is internal test infrastructure and is not published.

### `example-spring-boot3`

The example application is included in the repository as documentation and test
coverage support, but it is not a published library artifact.
