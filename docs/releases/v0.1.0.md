# hazelcast-toolkit v0.1.0

`hazelcast-toolkit` is a Spring Boot integration toolkit for Hazelcast focused on
reducing boilerplate around client configuration, Compact serialization, IMap
listeners, Hibernate second-level cache, and observability.

## Highlights

- Annotation-driven Compact registration with `@HzCompact`
- Automatic IMap listener registration with `@HzIMapListener`
- Spring Boot starters for Boot 2 and Boot 3
- Safer Hazelcast client naming with toolkit-level prefixing and unique generated
  fallback names when no naming inputs are configured
- Optional Hazelcast Enterprise license key support via
  `hazelcast.client.enterprise-license-key`
- Hibernate L2 integration with conservative defaults and support for:
  - `JCACHE`
  - `HAZELCAST_LOCAL`
  - `HAZELCAST`
- Re-enabled and stabilized near-cache invalidation integration coverage for Boot 2
  and Boot 3 Hibernate L2 scenarios
- Micrometer observability for Hazelcast near-cache and Hibernate L2
- Diagnostic endpoints and Actuator near-cache probe support
- Runnable Boot 3 example application with:
  - explicit Compact serializer
  - reflective Compact type
  - listener demo
  - Hibernate L2
  - near-cache demo
  - Management Center flow

## Key Capabilities

- Smart Hazelcast client naming with toolkit-level naming policy
- Compact scanning through a clean `ClassScanner` abstraction
- Serializer-aware Compact registration
- Automatic listener wiring for `@HzIMapListener`
- Shared integration test infrastructure across Boot 2 and Boot 3
- Production-oriented observability with Micrometer meters for:
  - near-cache metrics
  - Hibernate L2 metrics

## Notes

- For Hibernate L2 with `JCACHE`, prefer `extended-config=true` to bind Hibernate
  to the toolkit-managed `CacheManager`
- `HAZELCAST_LOCAL` is the recommended native region-factory mode for most
  Hazelcast client applications
- `hazelcast.toolkit.client.base-name` acts as the toolkit naming prefix; if no
  naming inputs are configured, the toolkit generates a unique fallback client name
- `hazelcast.client.enterprise-license-key` is optional and only needed when the
  application connects to Hazelcast Enterprise

## Not Included In This Release

### `toolkit-spring-boot4`

Boot 4 support exists in the repository, but it is intentionally **not** published
as part of `v0.1.0`.

Reason:

- Spring Boot `4.0.0` does not yet provide the JPA / Hibernate and Actuator runtime
  pieces required for full Hazelcast Hibernate L2 and Actuator support
- publishing the Boot 4 starter now would create misleading expectations because
  some requested features would become silent no-ops at runtime

Boot 4 will be reconsidered for publication once runtime support is real,
test coverage is stable, and the starter behavior is non-misleading.

### `toolkit-testcontainers`

`toolkit-testcontainers` is internal test infrastructure and is not published.

### `example-spring-boot3`

The example application is included in the repository as documentation and test
coverage support, but it is not a published library artifact.
