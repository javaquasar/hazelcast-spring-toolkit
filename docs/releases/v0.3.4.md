# hazelcast-toolkit v0.3.4

`hazelcast-toolkit` v0.3.4 is an auto-configuration hardening patch for the
`0.3.x` maintenance line.

## Why 0.3.4

The previous `0.3.x` patches focused on near-cache actuator typing,
diagnostics, metadata, and release confidence. This patch strengthens the
Spring Boot auto-configuration contract across Boot 2, Boot 3, and Boot 4.

## Highlights

- add Boot 3 and Boot 4 auto-configuration condition tests mirroring the Boot 2
  coverage
- verify that the diagnostic HTTP controller is controlled by
  `hazelcast.toolkit.metrics.diagnostic-endpoint.enabled`
- verify that Micrometer `MeterBinder` beans are controlled separately by
  `hazelcast.toolkit.metrics.enabled`
- verify that metrics binders do not require a `MeterRegistry` during bean
  creation
- verify that the `hazelcastNearCache` actuator endpoint requires explicit
  enablement and an `EntityManagerFactory`
- verify that the actuator endpoint backs off when JPA is absent
- make `HzToolkitMetricsController` back off when a user-defined controller bean
  is present
- verify user-defined bean precedence for:
  - `HazelcastNearCacheEndpoint`
  - `HazelcastNearCacheMetricsBinder`
  - `HibernateL2MetricsBinder`
  - `HzToolkitMetricsController`

## Compatibility

No user-facing property names change in this release.

This release only tightens auto-configuration behavior and tests. Applications
that define their own toolkit beans should now get the expected
`@ConditionalOnMissingBean` back-off behavior for the diagnostic HTTP
controller as well.

## Verification

Targeted checks:

```bash
./gradlew :toolkit-spring-boot2:test --tests io.github.javaquasar.hazelcast.toolkit.springboot2.config.Boot2AutoConfigurationConditionTest
./gradlew :toolkit-spring-boot3:test --tests io.github.javaquasar.hazelcast.toolkit.springboot3.config.Boot3AutoConfigurationConditionTest
./gradlew :toolkit-spring-boot4:test --tests io.github.javaquasar.hazelcast.toolkit.springboot4.config.Boot4AutoConfigurationConditionTest
```

For a full release confidence pass:

```bash
./gradlew build -PreleaseVersion=0.3.4
```

For a signed release bundle build:

```bash
./gradlew clean centralBundleAll -PreleaseVersion=0.3.4
```
