# Release Notes: v0.12.1

## Lite Member Mode

- Added `hazelcast.toolkit.member.lite-member` for Spring Boot 2, 3, and 4
  applications running with `hazelcast.toolkit.instance.mode=member`.
- Setting the property to `true` starts a Hazelcast lite member that joins the
  cluster without owning primary or backup partitions.
- Lite members route map and cache operations to data members, so application
  startup and shutdown do not move partition data to or from the application.
- Added Spring configuration metadata for IDE completion and property help.

## Migration

- No configuration change is required for existing member-mode applications.
  The new property defaults to `false`, preserving full-member behavior.
- Applications that use member mode as a fallback from client mode can set:

  ```properties
  hazelcast.toolkit.instance.mode=member
  hazelcast.toolkit.member.lite-member=true
  ```

- A lite member still participates in the cluster membership view and requires
  member network access, compatible security, and the same cluster name.

## Publication Warning Cleanup

- Replaced the deprecated internal Hazelcast client routing enum with the
  supported public `com.hazelcast.client.config.RoutingMode` API while
  preserving `smart-routing=false` behavior.
- Removed unresolved optional Spring links from published Javadocs without
  adding Spring dependencies to the core runtime modules.
- Completed optional annotation classpaths used during starter compilation and
  Javadoc generation without adding runtime dependencies.
- Updated the Boot 4 Actuator endpoint to use JSpecify nullability annotations
  instead of Spring's deprecated annotation.
- Updated artifact upload steps to `actions/upload-artifact@v7`, which runs on
  Node.js 24.

## Compatibility

- Java remains `17`.
- The Hazelcast baseline remains `5.7.0`.
- Spring Boot `2.7.18`, `3.5.7`, and `4.0.0` remain the supported build lines.
- Existing `HazelcastMemberFactory` method signatures remain available and
  retain full-member behavior; new overloads expose the lite-member option.
