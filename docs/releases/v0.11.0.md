# Release Notes: v0.11.0

## Compatibility

- Added a Hazelcast compatibility workflow that verifies the starter test suite
  against Hazelcast `5.5.0`, `5.6.0`, and `5.7.0`.
- Documented the Hazelcast version policy: compile against the lowest supported
  Hazelcast line and verify newer supported minor lines through the CI matrix.
- Documented known compatibility debt for client routing configuration:
  `RoutingMode` and `ClusterRoutingConfig#setRoutingMode(...)` compile with
  removal warnings on Hazelcast `5.7.0`.

## Verification

- Verified `toolkit-runtime` tests with Hazelcast `5.7.0`.
- Verified `toolkit-spring-boot3` tests with Hazelcast `5.7.0`.
