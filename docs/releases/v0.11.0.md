# Release Notes: v0.11.0

## Compatibility

- Updated the compile and runtime baseline from Hazelcast `5.5.0` to `5.7.0`.
- Updated the Hazelcast compatibility workflow to verify every starter against
  the `5.7.0` baseline.
- Updated the public compatibility policy and project metadata for Hazelcast 5.7.
- Documented known compatibility debt for client routing configuration:
  `RoutingMode` and `ClusterRoutingConfig#setRoutingMode(...)` compile with
  removal warnings on Hazelcast `5.7.0`.

## Verification

- Verified `toolkit-runtime`, all Spring Boot starters, and both example
  applications with Hazelcast `5.7.0` through a clean full build.
- Verified generated Maven publication metadata for release version `0.11.0`.
- Verified that `hazelcast-spring` remains absent from the default runtime
  classpath of the Spring Boot 2, 3, and 4 starters.
