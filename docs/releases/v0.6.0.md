# hazelcast-toolkit 0.6.0

## Focus

Cache modes maturity: make Spring Cache and Hibernate L2 mode choices easier to
reason about in legacy and modern services.

## Changes

- Strengthened Boot 2, Boot 3, and Boot 4 Spring Cache mode coverage for
  user-provided Spring `CacheManager` beans.
- Added tests proving user-defined Spring `CacheManager` beans win in `JCACHE`,
  `NATIVE`, and `NONE` modes.
- Added tests proving `hazelcast.toolkit.spring-cache.mode=native` still keeps a
  `javax.cache.CacheManager` bean available for Hibernate L2 / JCache-oriented
  integration while exposing Hazelcast's native Spring `CacheManager`.
- Added `docs/cache-modes-maturity.md` with recommended mode combinations,
  a JCache-to-native Spring Cache migration recipe, and notes for services that
  provide their own Spring `CacheManager`.
