# hazelcast-toolkit 0.4.0

## Focus

Consumer-grade observability.

## Changes

- Added an opt-in Hazelcast toolkit health indicator for Boot 2, Boot 3, and
  Boot 4 starters.
- New property:

```properties
hazelcast.toolkit.health.enabled=true
```

- The indicator contributes Hazelcast client readiness details to
  `/actuator/health` when Spring Boot Actuator health support is present.
- Health details include `instanceName`, `lifecycleRunning`, `clusterState`, and
  `memberCount`.
- The indicator reports `UP` when the toolkit-managed Hazelcast client is running
  and at least one cluster member is visible; otherwise it reports `DOWN`.
- Added configuration metadata for `hazelcast.toolkit.health.enabled`.
- Added dedicated health indicator contract tests for `UP`, stopped lifecycle,
  zero-member, and exception cases.
- Added `docs/actuator-operations.md` with production exposure guidance for
  health, metrics, the active near-cache probe, and `/hz-toolkit` diagnostics.
- Added `docs/prometheus-grafana-examples.md` with starter Prometheus queries and
  a Grafana dashboard draft.
- Expanded observability docs with a surface comparison table for health,
  Micrometer, active probe, and diagnostics.
