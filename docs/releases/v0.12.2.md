# Release Notes: v0.12.2

## Publication Warning Cleanup

- Replaced the deprecated internal Hazelcast client routing enum with the
  supported public `com.hazelcast.client.config.RoutingMode` API.
- Preserved the existing routing contract: `smart-routing=false` selects
  single-member routing, while `smart-routing=true` keeps all-members routing.
- Removed unresolved optional Spring references from generated Javadocs and
  completed compile-only annotation classpaths for the supported Spring Boot
  lines.
- Updated the Spring Boot 4 actuator nullability annotation to JSpecify.
- Updated artifact upload steps to `actions/upload-artifact@v7` for the current
  GitHub Actions runtime.

## Compatibility

- Java remains `17`.
- The Hazelcast baseline remains `5.7.0`.
- Spring Boot `2.7.18`, `3.5.7`, and `4.0.0` remain the supported build lines.
- No toolkit property or public API behavior changes are required for this
  release.
- Added annotation dependencies remain compile-only or test-only and are not
  published as runtime dependencies.

## Verification

- Verify both `ALL_MEMBERS` and `SINGLE_MEMBER` client routing modes in
  `HazelcastClientFactoryTest`.
- Run the affected runtime and Spring Boot 4 test suites.
- Generate Javadocs and the Maven Central aggregate bundle without the
  publication warnings addressed by this release.
- Validate the release automation with `node --test scripts/*.test.mjs` and
  `node scripts/validate-release-notes.mjs 0.12.2` after the release files are
