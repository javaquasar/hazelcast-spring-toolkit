# hazelcast-toolkit 0.3.5

## Focus

Consumer confidence for Spring Boot 2 releases.

## Changes

- Added `example-spring-boot2`, a minimal Boot 2 consumer smoke module.
- The smoke can run against local project modules or against a published
  `hazelcast-toolkit-spring-boot2` version using `-PusePublishedToolkit=true`.
- Hardened Hibernate L2 metrics auto-configuration so the binder is created
  only when an `EntityManagerFactory` bean is present, not merely when the JPA
  API is on the classpath.
- Extended the manual `published-consumer-smoke` GitHub Actions suite to verify
  both Boot 2 and Boot 3 published starter consumption.
- Updated release documentation so post-release verification covers the Services
  runtime line directly, not only the Boot 3 demo application.
- Added a draft compatibility matrix for Boot, Hibernate, Hazelcast, JPA, and
  JCache assumptions.
- Expanded observability and near-cache actuator troubleshooting docs with
  response contract examples.
- Updated the starter roadmap to keep 0.3.x focused on compatibility, docs, and
  consumer confidence hardening.

## Verification

```bash
./gradlew :example-spring-boot2:test
```

After publishing:

```bash
./gradlew :example-spring-boot2:test -PusePublishedToolkit=true -PtoolkitReleaseVersion=0.3.5
./gradlew :example-spring-boot3:test -PusePublishedToolkit=true -PtoolkitReleaseVersion=0.3.5
```

Or run the `Integration Tests` workflow with the `published-consumer-smoke`
suite and `toolkit_version=0.3.5`.
