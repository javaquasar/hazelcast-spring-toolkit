# hazelcast-toolkit 0.8.0

## Focus

Release confidence: make the tag-to-Central path easier to verify before a
release is pushed.

## Changes

- Added `docs/release-confidence-checklist.md` with pre-tag checks, GitHub
  Actions release behavior, manual dry-run guidance, and published-consumer
  smoke commands.
- Added generated publication metadata verification notes covering staged
  artifacts, signatures, POM metadata, and optional dependency checks.
- Added version-neutral tag, dry-run, and rollback command templates for
  reusable release documentation.
- Added condition coverage for native Hibernate mode fallback to the actual
  toolkit-managed `HazelcastInstance` name when a stale native client instance
  name is already present.
- Added a `0.8.0` roadmap section focused on release confidence and metadata
  guardrails.

## Verification

git diff --check
