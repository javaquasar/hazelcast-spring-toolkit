# hazelcast-toolkit 0.7.0

## Focus

Production recipes: make the starter easier to apply in real Hazelcast client
services, not only in isolated auto-configuration tests.

## Changes

- Added `docs/production-recipes.md` with a multi-service Hazelcast client
  setup, Services-style observability baseline, rolling deploy near-cache
  checklist, and native Spring Cache migration recipe.
- Linked production recipes from the README and roadmap so teams can find the
  operational guidance from the main entry points.
